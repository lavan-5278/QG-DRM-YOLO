# SERA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a zero-initialised cross-scale semantic evidence aggregator before P3 detection and screen it under the matched SCB-Dataset3-S protocol.

**Architecture:** SERA projects and upsamples P4/P5 to P3, gates the sum with P3/context evidence and adds it through a learnable zero-initialised gain.  Detect receives the refined P3 with untouched P4/P5, so normal loss and inference remain unchanged.

**Tech Stack:** Python 3.11, PyTorch/CUDA, Ultralytics 8.3.247, pytest, SCB-Dataset3-S.
