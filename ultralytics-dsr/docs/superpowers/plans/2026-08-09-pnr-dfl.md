# PNR-DFL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a training-only perspective-normalized DFL residual to the matched YOLO baseline and screen it with the established SCB-Dataset3-S protocol.

**Architecture:** `PNRDetectionLoss` subclasses `v8DetectionLoss`, repeats its matched-anchor calculation, and folds a geometry-weighted DFL expectation residual into the existing DFL log column.  The YAML contains `pnr` configuration; `DetectionModel` chooses the criterion without changing the normal `Detect` head.

**Tech Stack:** Python 3.11, PyTorch/CUDA, Ultralytics 8.3.247, pytest, SCB-Dataset3-S.

## Global Constraints

- Do not use Git or alter unrelated user files.
- PNR-DFL must not change head parameters, raw prediction channels, decoded inference layout, or NMS.
- Use alpha=1.0, lambda_pnr=0.25, scale_floor=1.0 and the exact matched baseline training protocol.
- Promote only if best mAP50-95 >= 0.47210; seed 42 is screening evidence only.
