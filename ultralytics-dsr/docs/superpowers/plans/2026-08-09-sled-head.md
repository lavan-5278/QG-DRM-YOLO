# SLED-Head Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add and evaluate a Spatial Layout Evidence Decoupling detection head that gates classification features by vertical upper-body layout while preserving normal YOLO regression and inference contracts.

**Architecture:** `SLEDDetect` inherits `Detect`.  Per detection scale, `SLEDLayoutGate` produces an identity-initialised vertical-layout gated copy for `cv3` classification and retains the original feature map for `cv2` regression.  Because concatenated channels and decoding remain unchanged, normal `v8DetectionLoss` and NMS are reused.

**Tech Stack:** Python 3.11, PyTorch/CUDA, Ultralytics 8.3.247, pytest, SCB-Dataset3-S.

## Global Constraints

- Do not use Git or change unrelated user files.
- Keep raw training channels `4 * reg_max + nc` and inference shape `[B, 4 + nc, anchors]` exactly compatible with `Detect`.
- Do not alter the strict matched 300-epoch protocol or use data outside SCB-Dataset3-S.
- Promote only at best mAP50-95 >= 0.47210; treat seed 42 as screening only.

class SLEDDetect(Detect):
    def forward(self, x):
        for i in range(self.nl):
            original = x[i]
            x[i] = torch.cat((self.cv2[i](original), self.cv3[i](self.sled[i](original))), 1)
        return super().forward(x)  # replace with Detect inference branch after avoiding a second head pass
