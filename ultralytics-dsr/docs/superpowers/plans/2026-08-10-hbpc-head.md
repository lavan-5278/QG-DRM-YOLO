# HBPC-Head Implementation Plan

> **For agentic workers:** Execute inline task-by-task with test-first checks. This workspace is intentionally operated without Git or worktrees at the user's request.

**Goal:** Add a Head–Behaviour-Part Complementarity YOLO11 detection head, verify its contracts, and run the strict SCB-Dataset3-S single-module screening protocol.

**Architecture:** `HBPC` forms upward and downward local directional evidence at every FPN scale, combines their projected features through an interaction mixer, and applies a zero-initialized residual class-feature gate. `HBPCDetect` retains standard `Detect.cv2` box features and sends only the `cv3` class features through HBPC.

**Tech Stack:** Python, PyTorch, Ultralytics YOLO11, pytest, YAML.

## Global Constraints

- Do not use Git or create a worktree.
- Input/output shape and standard YOLO training/inference contracts are unchanged.
- Regression receives original features; only class logits receive HBPC features.
- Use the strict matched baseline protocol and evaluate best mAP50-95 against 0.47010.
- Promote only at best-score delta >= +0.00200; state the single-seed limitation.
