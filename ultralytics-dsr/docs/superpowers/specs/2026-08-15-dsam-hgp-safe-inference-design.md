# DSAM/HGP 安全社交推理设计

## 目标

为 `YOLOv8n + DSAM/HGP` 建立一个保守的社交推理路径：它只能细化高质量检测候选，且绝不以社交分类器的 Softmax 输出覆盖 YOLO 的原始类别分数。

## 已确认问题与依据

暂停实验的同一 `best.pt` 在两种推理方式上的指标如下：

| 推理方式 | Precision | Recall | mAP50 | mAP50-95 |
|---|---:|---:|---:|---:|
| 原始 YOLO 检测输出 | 0.6501 | 0.6642 | 0.6945 | 0.5051 |
| 现有 DSAM/HGP 社交细化输出 | 0.0985 | 0.2847 | 0.1206 | 0.0650 |

现有实现对所有原始最大类别分数大于 0.05、且仍未经过 NMS 的候选运行社交分支。随后它将每个候选的整个类别向量置零，并写入社交分类器 Softmax 的最大概率。三分类 Softmax 最大概率不会低于约 1/3，因此原本低置信的背景候选会被人为抬分并进入 NMS。训练期的社交分类头却只在 GT RoI 上接受监督，形成明显的候选分布不一致。

## 范围

本试点仅改动 DSAM/HGP 的共享推理分支及其 YAML 配置，不恢复训练，不触碰 SSR/SSL 或完整 DSA 的训练队列。

### 包含

- 在检测 NMS 后选择有限、可靠的候选供社交分支使用。
- 仅以受限残差校正 YOLO 已预测类别的分数。
- 保留原始盒、原始类别和所有未选候选；不做分类重指派。
- 在候选不足、非有限张量或社交分支报错时逐图回退原始检测输出。
- 提供单元与集成回归测试，以及暂停 checkpoint 的前后验证对照。

### 不包含

- 不重新设计训练目标中的 proposal 正负样本匹配。
- 不改变 DSAM/HGP 试点的框坐标。
- 不恢复或续训已经暂停的作业。
- 不自动将该路径推广至 SSR/SSL 和完整 DSA。

## 架构与数据流

1. 保留 Detect 头的原始 `xywh + nc` 输出。
2. 按 Ultralytics 相同的推理阈值与 NMS 得到检测结果；将结果映射回各图的原始候选索引。
3. 仅选择置信度不低于 `0.25` 的已 NMS 候选，按原始置信度降序截断到每图 `64` 个。
4. 从这些候选提取 RoI，运行 HGP 和 DSAM 分类头。
5. 对每个候选仅读取其原始预测类别 `c` 的社交 logit `s_c`；不采用 `argmax`，不重写类别向量。
6. 将原始概率 `p_c` 转换为 logit，计算 `sigmoid(logit(p_c) + alpha * s_c)`，其中 `alpha=0.15`。结果只写回 `c` 这一项，其他类别保持原值；分数再夹紧到 `[eps, 1-eps]`。
7. 所有未选候选、框坐标、类别索引都保持 Detect 原值。任何防护条件失败时返回未修改预测。

## 配置接口

`dsa.inference_refinement` 使用以下字段：

```yaml
inference_refinement:
  enabled: true
  candidate_confidence: 0.25
  max_candidates: 64
  score_alpha: 0.15
  min_candidates: 2
```

字段必须满足：`candidate_confidence` 与 `score_alpha` 位于 `[0, 1]`，`max_candidates >= 1`，`min_candidates >= 2`。配置缺失时，默认关闭社交推理，以保证现有或未来模型可安全退化为原始 YOLO 输出。

## 保护与错误处理

- `enabled=false` 时输出与原始 Detect 逐元素相同。
- 不足 `min_candidates`、候选或社交输出非有限、形状不匹配、NMS 索引无法映射时，该图直接回退原始预测。
- 试点不改变候选框坐标，避免分类融合与回归质量问题相互混淆。
- 融合函数不生成新的候选，不提升未经过 NMS 的背景候选。

## 验收标准

1. 低分候选不会被社交路径提高；关闭细化与原始输出逐元素一致。
2. 细化不改变任何候选的原预测类别或框坐标。
3. 选中的候选数不超过 `64`，且均来自 NMS 后、置信度至少为 `0.25` 的集合。
4. 任意 NaN/Inf 社交输出会触发逐图原始输出回退。
5. 暂停 checkpoint 的安全融合验证 mAP50-95 不低于原始检测器的 0.5051；若未达到，不启动重训。
6. 仅在上述验证通过后，才安排新的 DSAM/HGP 从头训练试点。

## 测试策略

- 为候选选择与类别保持写纯张量单元测试。
- 为残差融合写数值边界测试：低分不抬升、仅原类别变化、`alpha=0` 恒等、非有限回退。
- 为 DSADetModel 写集成测试：禁用路径恒等、NMS 后候选截断、FP32 社交分支在 AMP 下保持有限。
- 使用同一暂停 checkpoint 在 5k_HRW 验证集上分别运行原始检测器和安全融合路径，记录四项指标与候选计数。

## 推广条件

仅当 DSAM/HGP 安全融合达到验收标准，才将同一候选选择与融合接口复用于 SSR/SSL 和完整 DSA；完整 DSA 仍保留 Mosaic/MixUp 关闭及 GT→预测框渐进混合的既定训练约束。
